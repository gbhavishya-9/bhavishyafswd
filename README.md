# College Web Assignment

This project contains three pages created for a college assignment:

- College Fest (HTML + CSS) — `CollegeFest/index.html`
- Font Changer (HTML + JS) — `FontChanger/index.html`
- Student Profile (HTML + external CSS) — `StudentProfile/index.html`

How to run

1. Open the `c:\Users\Student\Desktop\assiginment` folder in your editor.
2. Open any `index.html` file in a browser (double-click or use Live Server).

Upload to Git

From the `c:\Users\Student\Desktop\assiginment` folder run:

```bash
git init
git add .
git commit -m "Add assignment webpages"
git remote add origin <your-repo-url>
git push -u origin main
```

Replace `<your-repo-url>` with your GitHub repository URL.
